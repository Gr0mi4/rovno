# Статус «Ровно»

Обновлено: **11 сентября 2026**. Версия: **0.1.0, первая реализация**.

**Исходники готовы к дальнейшей проверке. Устанавливаемый release-APK пока не опубликован.** Не считать наличие файла `*-unsigned.apk` готовым приложением для телефона: такой APK требует подписи.

## Уже сделано

- [x] Изучены функции и отзывы на официальных страницах популярных конвертеров; ссылки и решения описаны в README.
- [x] Собственный интерфейс без рекламы, аккаунтов, подписок и аналитики.
- [x] Основные валюты: PLN, USD, EUR, BYN, RUB; одновременно на одном экране.
- [x] Переключение исходной валюты касанием с сохранением эквивалента суммы и порядка строк.
- [x] Простой калькулятор: `+`, `−`, `×`, `÷`, проценты, смена знака, стирание и очистка.
- [x] Поиск и добавление других валют из каталога, удаление лишних.
- [x] Тёмная, светлая и системная тема; сохранение настроек и ввода.
- [x] Копирование суммы кнопкой и удержанием строки.
- [x] Реальные ежедневные курсы Currency API: основной сервер и резервное зеркало.
- [x] Проверка резервного зеркала, если основной сервер отдаёт вчерашнюю таблицу; защита от замены более нового снимка старым.
- [x] Ручное обновление, обновление при открытии по истечении интервала, фоновая задача Android раз в шесть часов с учётом ограничений системы.
- [x] Сохранение последнего успешного снимка, дата курса, отображение ошибки обновления; нет выдуманных стартовых курсов.
- [x] Android-оболочка: Java + системный WebView, API 26+, target SDK 35, иконка, системные отступы, обработка кнопки «назад».
- [x] Внешний контент не допускается к Android-мосту; запросы курсов выполняются к фиксированным HTTPS-адресам.
- [x] Gradle-проект, тесты, документация и workflow GitHub Actions с артефактами сборки.
- [x] Подготовлена отдельная проверка запуска в эмуляторе через ручной запуск workflow с `emulator=true`.

## Что ещё предстоит

1. **Проверить Android-сборку в эмуляторе.** Запустить подготовленный smoke-test и проверить мост, калькулятор, системные отступы и кнопку «назад».
2. **Согласовать хранение ключа подписи релизов.** Для обновлений поверх установленного приложения нужен постоянный ключ. Его ещё не создавали и не загружали в секреты GitHub; в репозитории секретов нет. Автоматическая проверка разрешений потребовала отдельного согласования этого шага.
3. **Подписать APK и проверить подпись.** Проверить идентификатор `com.rovno.app`, версию, содержимое и отсутствие отладочного режима.
4. **Опубликовать релиз v0.1.0** с APK и контрольной суммой SHA-256, добавить прямую ссылку на скачивание в README.
5. **Протестировать на реальном Google Pixel:** первый запуск, отсутствие сети, восстановление кэша, переходы валют, небольшие и большие суммы, поиск валют с экранной клавиатурой, светлая/тёмная тема, поворот и увеличенный системный шрифт.
6. **Проверить обновление поверх предыдущей версии** и фактическое фоновое обновление под ограничениями батареи Android.
7. После обратной связи владельца скорректировать дизайн и удобство, затем выпускать новые версии с тем же ключом.

## Известные границы первой версии

- Курсы обновляются поставщиком ежедневно. Это справочные курсы, не котировки каждую секунду и не гарантированный курс конкретного банка.
- Для первой загрузки нужен интернет. Затем доступны последние сохранённые курсы с их датой.
- Добавление валюты означает выбор из встроенного каталога обычных валют; создание собственного токена или ручного курса пока не реализовано.
- Расчёты используют JavaScript Number; ввод ограничен 15 цифрами. Округление в списке до двух знаков служит отображению; не заменяет внутреннюю сумму при обычном переключении валют.
- Фоновые задачи запланированы в коде, но их выполнение на реальном Pixel ещё не проверено. Android может задерживать их ради экономии батареи.
- Превью в README показывает интерфейс браузера; оно не доказывает успешную установку APK.
