# Статус «Ровно»

Обновлено: **12 сентября 2026**. Версия: **0.1.0, первый публичный релиз**.

**Подписанный APK публикуется автоматически при push тега `v0.1.0`.** Постоянная ссылка: [releases/latest/download/rovno.apk](https://github.com/Gr0mi4/rovno/releases/latest/download/rovno.apk).

## Уже сделано

- [x] Изучены функции и отзывы на официальных страницах популярных конвертеров; ссылки и решения описаны в README.
- [x] Собственный интерфейс без рекламы, аккаунтов, подписок и аналитики.
- [x] Основные валюты: PLN, USD, EUR, BYN, RUB; одновременно на одном экране.
- [x] Переключение исходной валюты касанием с сохранением эквивалента суммы и порядка строк.
- [x] Калькулятор: `+`, `−`, `×`, `÷`, проценты (включая составные сценарии), смена знака, стирание и очистка.
- [x] Поиск и добавление других валют из каталога, удаление лишних; нельзя выбрать валюту без курса.
- [x] Тёмная, светлая и системная тема; сохранение настроек и ввода.
- [x] Копирование суммы кнопкой и long-press; адаптивная точность для малых сумм и zero-decimal валют.
- [x] Реальные ежедневные курсы Currency API: основной сервер и резервное зеркало.
- [x] Защита от замены более нового снимка старым; ручное и фоновое обновление.
- [x] Android: WebView hardening, `fontScale`, accessibility baseline, compact/landscape layout.
- [x] CI без signing secrets; release workflow fail-closed с `verify-apk.sh` и emulator smoke API 26/35.
- [x] `PRIVACY.md`, обновлённые `README.md` и `docs/RELEASING.md`.
- [x] Постоянный ключ подписи и GitHub secrets в environment `release`.

## Известные границы первой версии

- Курсы обновляются поставщиком ежедневно; это справочные значения, не котировки каждую секунду.
- Для первой загрузки нужен интернет; затем доступны последние сохранённые курсы с их датой.
- Расчёты используют JavaScript Number; ввод ограничен 15 цифрами.
- Фоновые задачи могут задерживаться Android ради экономии батареи.
